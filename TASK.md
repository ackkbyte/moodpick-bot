# Учебный проект: Telegram-бот «Что посмотреть?»

## Зачем этот проект

Сделай Telegram-бота, который помогает выбрать фильм или сериал по настроению.

Пример: пользователь пишет: «хочу что-то лёгкое и смешное», а бот находит подходящие варианты в своей небольшой базе. Пользователь может отметить вариант как понравившийся или добавить его в список «посмотреть позже».

Это учебный проект. Главная цель — не просто получить работающего бота с помощью ИИ, а понимать каждую часть: уметь запускать проект, объяснить его структуру и самостоятельно внести небольшое изменение.

## Что в итоге должно работать

### Основной сценарий

1. Пользователь запускает бота командой `/start`.
2. Бот приветствует пользователя и объясняет, что можно написать настроение или выбрать кнопку.
3. Пользователь отправляет текст, например:
   - `хочу что-то лёгкое и смешное`;
   - `хочу страшное`;
   - `хочу фантастику`;
   - `хочу короткий сериал`.
4. Бот ищет совпадения в собственной базе фильмов и сериалов.
5. Бот присылает до **трёх** рекомендаций. У каждой есть:
   - название;
   - тип: фильм или сериал;
   - год (если указан);
   - жанры/теги;
   - короткое описание;
   - кнопки **«❤️ Понравилось»** и **«🔖 Смотреть позже»**.
6. Нажатие кнопки сохраняет выбор конкретного пользователя в SQLite.
7. Команды `/favorites` и `/later` показывают сохранённые списки.

## Обязательные функции

### 1. Команды

Реализуй следующие команды:

| Команда | Что делает |
| --- | --- |
| `/start` | Приветствие и краткая инструкция |
| `/help` | Показывает примеры запросов и список возможностей |
| `/random` | Показывает случайный фильм или сериал из базы |
| `/favorites` | Показывает понравившиеся варианты пользователя |
| `/later` | Показывает список «посмотреть позже» |

### 2. Настроения и поиск

Не нужно создавать настоящий искусственный интеллект или подключать внешние кино-сервисы. Бот ищет по локальной базе и понятным правилам.

Сделай минимум такие соответствия:

| Что пишет пользователь | Теги, по которым искать |
| --- | --- |
| `смешное`, `лёгкое`, `весёлое`, `комедия` | `комедия`, `лёгкое`, `смешное` |
| `страшное`, `ужасы`, `жуткое` | `ужасы`, `страшное` |
| `грустное`, `драма`, `поплакать` | `драма`, `грустное` |
| `фантастика`, `космос`, `будущее` | `фантастика`, `космос` |
| `детектив`, `загадка`, `триллер` | `детектив`, `триллер` |
| `сериал` | `сериал` |
| `фильм` | `фильм` |

Допустимо сделать это обычным словарём ключевых слов. Если подходящего варианта нет, бот должен вежливо сообщить об этом и предложить попробовать другой запрос или `/random`.

### 3. Кнопки

Под сообщением с рекомендацией должны быть inline-кнопки:

- `❤️ Понравилось` — добавляет запись в избранное;
- `🔖 Смотреть позже` — добавляет запись в список просмотра;
- необязательно: `🎲 Ещё вариант` — показывает ещё одну рекомендацию.

При повторном нажатии одна и та же запись не должна появляться в списке дважды. Бот должен подтвердить действие коротким сообщением, например: «Добавлено в избранное».

### 4. База данных SQLite

Используй SQLite: это один файл базы рядом с проектом, отдельный сервер не нужен.

Нужно как минимум три таблицы:

```text
media
  id, title, media_type, year, description, tags

favorites
  id, telegram_user_id, media_id, created_at

watch_later
  id, telegram_user_id, media_id, created_at
```

Требования:

- база и таблицы создаются автоматически при первом запуске;
- `telegram_user_id` берётся из Telegram, а не вводится вручную;
- для пары `telegram_user_id + media_id` должен быть запрет на дубликаты;
- база `media` заполняется при первом запуске, если она пустая;
- добавь не меньше **20** фильмов и сериалов разных жанров;
- не храни токен бота в базе или в коде.

## Технологии

Используй простой и понятный стек:

- Python 3.11+;
- библиотека `python-telegram-bot` (или `aiogram`, но выбери только одну);
- встроенный модуль `sqlite3`;
- `.env` для секретов;
- `uv` для запуска и зависимостей, так как он уже используется в репозитории.

## Структура проекта

Можно немного изменить структуру, но код должен быть разложен по смыслу, а не лежать целиком в одном файле.

```text
moodpick-bot/
├── src/
│   ├── main.py          # запуск бота и обработчики Telegram
│   ├── database.py      # создание БД и запросы к ней
│   ├── catalog.py       # начальные фильмы/сериалы и поиск
│   └── config.py        # чтение настроек из .env
├── tests/               # необязательно, но желательно
├── .env.example         # пример переменных без настоящего токена
├── .gitignore
├── README.md
├── TASK.md
└── pyproject.toml
```

Названия файлов могут отличаться, если ты можешь объяснить их назначение.

## Безопасность и GitHub

### Секреты

1. Создай бота через `@BotFather` и получи токен.
2. Создай локальный файл `.env`:

   ```env
   BOT_TOKEN=сюда_вставляется_настоящий_токен
   ```

3. Добавь `.env` и файл SQLite (`*.db`) в `.gitignore`.
4. Создай `.env.example` без токена:

   ```env
   BOT_TOKEN=your_telegram_bot_token_here
   ```

**Никогда не отправляй настоящий токен в GitHub, чат с ИИ или скриншот.** Если токен всё-таки попал в публичный репозиторий, сразу перевыпусти его через BotFather.

### README

В `README.md` обязательно напиши:

1. что делает бот;
2. какие функции есть;
3. что нужно для запуска;
4. пошаговую установку;
5. как создать `.env` из `.env.example`;
6. команду запуска;
7. примеры сообщений для бота;
8. короткое описание структуры проекта;
9. скриншот или GIF работающего бота (если получится).

## План работы

Делай по маленьким этапам. После каждого этапа запускай проект и проверяй результат.

### Этап 1. Подготовка

- Изучи текущие файлы проекта.
- Создай виртуальное окружение/настрой зависимости через `uv`.
- Добавь нужные зависимости в `pyproject.toml`.
- Настрой `.gitignore` и `.env.example`.
- Сделай первый коммит: `chore: prepare project configuration`.

### Этап 2. Каталог и база данных

- Опиши минимум 20 объектов каталога.
- Создай функции инициализации SQLite.
- Реализуй добавление начального каталога без дубликатов.
- Проверь, что после первого запуска появился файл базы и таблицы.
- Сделай коммит: `feat: add media catalog and database setup`.

### Этап 3. Поиск по настроению

- Реализуй преобразование текста пользователя в теги.
- Реализуй поиск в каталоге.
- Проверь минимум 5 разных текстовых запросов.
- Отдельно проверь запрос без результатов.
- Сделай коммит: `feat: add mood-based media search`.

### Этап 4. Telegram-бот

- Подключи `/start`, `/help` и обработку обычных сообщений.
- Красиво отформатируй карточку рекомендации.
- Добавь `/random`.
- Проверь бота в настоящем Telegram.
- Сделай коммит: `feat: add telegram bot recommendations`.

### Этап 5. Избранное и «посмотреть позже»

- Добавь inline-кнопки и обработку нажатий.
- Сохраняй выбранные записи для конкретного пользователя.
- Реализуй `/favorites` и `/later`.
- Проверь, что повторное нажатие не создаёт дубликат.
- Сделай коммит: `feat: add favorites and watch later lists`.

### Этап 6. Финальная проверка

- Прочитай код и убери очевидные дублирования.
- Убедись, что токен нигде не закоммичен.
- Обнови README.
- Проверь запуск с чистой базой.
- Сделай финальный коммит: `docs: add project documentation`.

## Как работать с ИИ

ИИ — помощник, а не кнопка «сделай всё». Работай короткими итерациями.

### Хороший порядок действий

1. Сначала объясни ИИ свою текущую цель одним предложением.
2. Попроси его **сначала посмотреть текущие файлы**, а не переписывать проект целиком.
3. Проси сделать один маленький этап.
4. Прочитай изменения перед запуском.
5. Запусти код сам, скопируй ошибку полностью, если она есть.
6. Попроси ИИ объяснить непонятные строки простыми словами.
7. Только после проверки делай коммит.

### Примеры хороших запросов ИИ

```text
Посмотри структуру этого Python-проекта. Ничего не меняй: кратко скажи,
какие файлы уже есть и как лучше добавить Telegram-бота.
```

```text
Нужно реализовать только SQLite-слой для бота. Используй sqlite3,
создай таблицы media, favorites и watch_later. Покажи, какие файлы
изменишь, а затем внеси минимальные изменения.
```

```text
Объясни этот файл построчно простыми словами. Я новичок в Python.
Не меняй код.
```

```text
После запуска я получил эту ошибку: [вставить ошибку целиком].
Объясни причину, предложи минимальное исправление и не меняй файлы,
пока я не соглашусь.
```

```text
Проверь, не попадёт ли мой Telegram-токен в Git. Посмотри только
.gitignore, .env.example, README и git status. Не показывай секреты.
```

### Чего не делать

- Не вставляй в ИИ настоящий токен Telegram.
- Не проси «сделай весь проект сразу».
- Не принимай изменения, если не понимаешь, для чего они.
- Не запускай команды удаления, сброса Git или установки случайных пакетов без понимания.
- Не делай один огромный коммит в конце.
